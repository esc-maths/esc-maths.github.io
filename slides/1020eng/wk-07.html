Integration by Parts

Recall the product rule for differentiation: $\ds \frac{d}{dx}(uv)=u\,dv+v\,du.$

Integrating both sides gives

$\ds \int u\,dv = uv - \int v\,du.$

This method is useful when the integrand is a product of functions.




Trigonometric Substitution

This technique is used for integrals involving

$\sqrt{a^2-x^2},\ \sqrt{a^2+x^2},\ \sqrt{x^2-a^2}$.

These expressions resemble standard trigonometric identities.

We substitute $x$ using a trigonometric function to eliminate the square root.
For example, by setting $\, x=a\sin\theta,\,$ we can rewrite

$\ds \int \sqrt{a^2-x^2}\,dx\;$ $\ds= \int a\cos\theta\,d \theta.\;$

👉 $\;\sqrt{a^2-x^2} = \sqrt{a^2- a^2\sin^2\theta}$ $ = \sqrt{a^2\left(1- \sin^2\theta\right)}$ $ =\sqrt{a^2\cos^2\theta }$ $ =a\cos\theta $

The integral is rewritten in terms of $\theta$ and evaluated using trigonometric rules.




Partial Fractions

This method applies to rational functions: $\ds \frac{P(x)}{Q(x)}$, where $\deg P < \deg Q$.

The idea is to decompose the integrand into simpler fractions.

$\ds \frac{1}{(x-1)(x+2)}=\frac{A}{x-1}+\frac{B}{x+2}$

Each term can then be integrated directly.




Summary of Integration Techniques

Method When to use Key idea
Integration by parts Products of functions Reverse the product rule
Trigonometric substitution Radicals with $a^2\pm x^2$ Use trig identities to simplify
Partial fractions Rational functions Decompose into simpler terms
