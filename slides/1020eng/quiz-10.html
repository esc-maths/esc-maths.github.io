Question

Consider the ODE $\,y' -2y = -4x + 2.$

  1. Find the general solution of the homogeneous differential equation $\,y' -2y =0.$
  2. Solve the ODE with the initial condition $y(0)=1.$




Solution Question 1.

General solution of the homogeneous ODE: $y' - 2y = 0.$

This is a separable equation: $ \ds \frac{1}{y}\frac{dy}{dx} = 2. $

Integrating we get $\;\ln |y| = 2x + C.$

Thus the solution to the homogeneous ODE \[ y_H = C e^{2x}. \]


Solution Question 2. Solve $\,y' -2y = -4x + 2$ with $y(0)=1.$

👉 $\; y = y_H + y_P $ $ = Ce^{2x} + y_P $

Since the right-hand side is linear $-4x + 2,$ we try a linear particular solution

$ y_P = ax + b. $

Then $ y_P' = a.$ Substitute in the ODE: $ a - 2(ax + b) = -4x + 2. $

Match coefficients: $ \;\,-2a = -4 \;\, \Rightarrow \;\; a = 2, $

$ a - 2b = 2 \; \Rightarrow $ $ \; 2 - 2b = 2 $ $ \; \Rightarrow\; b = 0. $

Therefore the particular solution is $ \;y_P = 2x. $


Solution Question 2. Solve $\,y' -2y = -4x + 2$ with $y(0)=1.$

👉 $\; y = y_H + y_P $ $ = Ce^{2x} + y_P $ $ = Ce^{2x} + 2x $

Apply the initial condition \(y(0)=1\):

$ 1 = C + 0 $ $ \Rightarrow C = 1. $

Therefore the solution is $$ y(x) = e^{2x} + 2x. $$
