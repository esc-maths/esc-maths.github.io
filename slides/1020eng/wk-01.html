A Couple of Important Functions

Function Inverse Domain Range
$f(x)=e^x$ $f^{-1}(x)=\ln x$ $(-\infty,\infty)$ $(0,\infty)$
$g(x)=\ln x$ $g^{-1}(x)=e^x$ $(0,\infty)$ $(-\infty,\infty)$

These functions are inverses to each other since:

\( e^{\ln x}=x \quad (x>0), \qquad \ln(e^x)=x \)

Some Important Identities

Trigonometric
$\sin^2 x + \cos^2 x = 1$
$1 + \tan^2 x = \sec^2 x$
$\sin x=\dfrac{1}{\csc x},\;\cos x=\dfrac{1}{\sec x}$
$\tan x=\dfrac{\sin x}{\cos x}$
$\sin(2x) = 2\sin x\cos x$
$\cos(2x) = \cos^2x- \sin ^2x$

Hyperbolic Trigonometric
$\sinh x=\dfrac{e^x-e^{-x}}{2},\; \cosh x=\dfrac{e^x+e^{-x}}{2}$
$\cosh^2 x - \sinh^2 x = 1$
$\tanh x=\dfrac{\sinh x}{\cosh x}$
$\sech x=\dfrac{1}{\cosh x},\;\csch x=\dfrac{1}{\sinh x}$
$\sinh(2x) = 2\sinh x\cosh x$
$\cos(2x) = \cosh^2x+ \sinh ^2x$

Hyperbolic Trigonometric Identities

Definitions $\sinh x=\dfrac{e^x-e^{-x}}{2},\quad \cosh x=\dfrac{e^x+e^{-x}}{2}$
Pythagorean $\cosh^2 x - \sinh^2 x = 1$
Quotient $\tanh x=\dfrac{\sinh x}{\cosh x}$
Reciprocal $\sech x=\dfrac{1}{\cosh x},\;\csch x=\dfrac{1}{\sinh x}$
