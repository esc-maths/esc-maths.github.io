Bonus Quiz


Question 1

Evaluate $\ds \lim_{x\to -5}\frac{x^2-25}{x+5}$

Question 2

Find $\ds\frac{dy}{dx}$ if $\ds y = \sin\left(x^2\right)$

Question 3

For what value of $x$ does $f(x)=xe^{-x}$ have its maximum value?

Question 4

Find $\ds \int e^{3x}\,dx$


Solution Question 1

We evaluate the limit $\ds \lim_{x\to -5}\frac{x^2-25}{x+5}$. Factor the numerator.

\(\ds \frac{x^2-25}{x+5} = \frac{(x-5)(x+5)}{x+5}\) \(\ds = x-5 \quad (x \neq -5)\)


Now take the limit: \(\;\ds \lim_{x\to -5}(x-5) = -10.\)



Solution Question 2

We are given $\ds y = \sin(x^2)$. This is a composition of functions.

Using the chain rule:

 \(\ds \frac{dy}{dx} = \cos(x^2)\cdot \frac{d}{dx}(x^2)\)


Therefore \(\ds\, \frac{dy}{dx} = 2x\cos(x^2).\)



Solution Question 3

We want to find the maximum of $\ds f(x)=xe^{-x}$. Differentiate the function.

Using the product rule: \(\ds f'(x)=e^{-x}-xe^{-x}\) \(\ds = e^{-x}(1-x)\)

Set $f'(x)=0:\,$ So \(\ds \,e^{-x}(1-x)=0\,\) \(\ds\, \Rightarrow x=1.\)

Using the second derivative test we have:

\(\ds f''(x)= -e^{-x}-e^{-x}+xe^{-x}\)

\(\ds f''(1)=-e^{-1}-e^{-1}+e^{-1}\) \(\ds = -e^{-1} \) \(\lt 0\)

Therefore, $f(x)$ has a maximum at $\ds x=1$.


Solution Question 4

We evaluate the integral $\ds \int e^{3x}\,dx$. Use substitution.

Let $u=3x,\,$ so $\,du=3\,dx$.


\(\ds \int e^{3x}\,dx = \frac{1}{3}\int e^{u}\,du\) \(\ds = \frac{1}{3}e^{u}+C\) \(\ds = \frac{1}{3}e^{3x}+C.\)
