Question 1

Find $\ds \frac{dy}{dx}$ if

  1. $y = e^{5x}$
  2. $y =x^2 \sin (x) $

Question 2

Use implicit differentiation to find an expression for the slope of the curve given by $9y^2+ 4x^2=36$



Question 1

  1. If $y = e^{5x},\,$ then $\,\dfrac{dy}{dx} = 5e^{5x}.$
  2. If $y =x^2 \sin (x) ,\,$ then $\,\dfrac{dy}{dx} = x^2\cos(x) +2x \sin(x) .$

Question 2

Given $9y^2+ 4x^2=36,\,$ then $\,18 y \dfrac{dy}{dx}+ 8x = 0.$ Solve for $\dfrac{dy}{dx}.$

Hence $\dfrac{dy}{dx}= -\dfrac{4x}{9y}.$
