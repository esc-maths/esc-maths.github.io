Linear Transformations

Mapping

Consider the mapping (transformation) from $\mathbb{R}^2 \mapsto \mathbb{R}^2$, given by:

$(x,y) \mapsto (-y,x)$

This mapping rotates vectors through an angle of $90^{\circ}$ (anticlockwise).

Linear Transformations

Definition

A mapping $T$ from a vector space $V$ into a vector space $W$ (written $T:V \rightarrow W$) is said to be a linear transformation, if for all $\mathbf{u}, \mathbf{v} \in V$ and $\alpha, \beta \in \mathbb{R}$:

$$T(\mathbf{u}+\mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})$$ and $\quad T(\alpha \mathbf{u}) = \alpha T(\mathbf{u})$

or equivalently:

$$T(\alpha \mathbf{u} + \beta \mathbf{v}) = \alpha T(\mathbf{u}) + \beta T(\mathbf{v})$$

Linear Transformations

Example of a Linear Transformation (1)

Suppose $T$ is an anti-clockwise rotation by $90^{\circ}$ in the $x$-$y$ plane.

Geometrically, we see that the components track linearly with the vector addition parallelogram:

$$T(\mathbf{u}+\mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})$$

Linear Transformations

Example of a Linear Transformation (2)

Similarly, scaling a vector before or after the transformation preserves proportional size:

$$\alpha T(\mathbf{v}) = T(\alpha \mathbf{v})$$

Therefore, the scalar homogeneity rule $T(\alpha \mathbf{v}) = \alpha T(\mathbf{v})$ is satisfied.

Linear Transformations

A Mapping That is Not a Linear Transformation

$T:\mathbb{R}^2 \rightarrow \mathbb{R}^2$ given by $T\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x + 1 \\ y \end{pmatrix}$

Let $\mathbf{u} = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$ and $\mathbf{v} = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$. Then:

$$\mathbf{u}+\mathbf{v} = \begin{pmatrix} 3 \\ 2 \end{pmatrix} \implies T(\mathbf{u}+\mathbf{v}) = \begin{pmatrix} 4 \\ 2 \end{pmatrix}$$

But calculating individual mappings gives:

$$T(\mathbf{u}) = \begin{pmatrix} 3 \\ 1 \end{pmatrix}, \quad T(\mathbf{v}) = \begin{pmatrix} 2 \\ 1 \end{pmatrix} \implies T(\mathbf{u}) + T(\mathbf{v}) = \begin{pmatrix} 5 \\ 2 \end{pmatrix}$$

Since $T(\mathbf{u}) + T(\mathbf{v}) \neq T(\mathbf{u}+\mathbf{v})$, this is NOT a linear transformation.

Note: You can disprove linearity with a single counterexample. To prove a mapping is a linear transformation, you must show it holds generally.

Class Examples

  2. Determine whether the transformation $T:\mathbb{R}^2 \mapsto \mathbb{R}^3$ is linear: $$T\begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = \begin{pmatrix} x_1 \\ x_2 \\ x_1^2 + x_2^2 \end{pmatrix}$$

Linear Transformations

Proving a Mapping is a Linear Transformation (a)

Consider another transformation on $\mathbb{R}^2$ given by $T(\mathbf{v}) = 3\mathbf{v}$. We check the properties to confirm that $T$ is linear.

(a) Check whether $T(\mathbf{u}+\mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})$

Let $\mathbf{u} = \begin{pmatrix} u_1 \\ u_2 \end{pmatrix}$ and $\mathbf{v} = \begin{pmatrix} v_1 \\ v_2 \end{pmatrix}$, so $\mathbf{u}+\mathbf{v} = \begin{pmatrix} u_1 + v_1 \\ u_2 + v_2 \end{pmatrix}$:

$$T(\mathbf{u}+\mathbf{v}) = T\begin{pmatrix} u_1 + v_1 \\ u_2 + v_2 \end{pmatrix} = 3\begin{pmatrix} u_1 + v_1 \\ u_2 + v_2 \end{pmatrix} = \begin{pmatrix} 3u_1 + 3v_1 \\ 3u_2 + 3v_2 \end{pmatrix}$$ $$= 3\begin{pmatrix} u_1 \\ u_2 \end{pmatrix} + 3\begin{pmatrix} v_1 \\ v_2 \end{pmatrix} = T(\mathbf{u}) + T(\mathbf{v})$$

Linear Transformations

Proving a Mapping is a Linear Transformation (b)
(b) Check whether $T(\alpha \mathbf{u}) = \alpha T(\mathbf{u})$

Using the definition for scalar multiplication with $\alpha \in \mathbb{R}$:

$$T(\alpha \mathbf{u}) = T\begin{pmatrix} \alpha u_1 \\ \alpha u_2 \end{pmatrix} = 3\begin{pmatrix} \alpha u_1 \\ \alpha u_2 \end{pmatrix} = \alpha \left[ 3\begin{pmatrix} u_1 \\ u_2 \end{pmatrix} \right] = \alpha T(\mathbf{u})$$

Both criteria are satisfied, confirming $T$ is a linear transformation!

Linear Transformations

Using the Alternate Definition (1)

Consider the mapping from $\mathbb{R}^2$ to $\mathbb{R}^3$ given by:

$$T\begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = (x_2, x_1, x_1 + x_2)^T = \begin{pmatrix} x_2 \\ x_1 \\ x_1 + x_2 \end{pmatrix}$$

We will show that this is linear using the combined equivalent rule: $T(\alpha \mathbf{u} + \beta \mathbf{v}) = \alpha T(\mathbf{u}) + \beta T(\mathbf{v})$.

Let $\mathbf{u} = \begin{pmatrix} u_1 \\ u_2 \end{pmatrix}$ and $\mathbf{v} = \begin{pmatrix} v_1 \\ v_2 \end{pmatrix}$. Then:

$$\alpha \mathbf{u} + \beta \mathbf{v} = \begin{pmatrix} \alpha u_1 + \beta v_1 \\ \alpha u_2 + \beta v_2 \end{pmatrix}$$

Linear Transformations

Using the Alternate Definition (2)

Recall $\alpha \mathbf{u} + \beta \mathbf{v} = \begin{pmatrix} \alpha u_1 + \beta v_1 \\ \alpha u_2 + \beta v_2 \end{pmatrix}$. Applying the rules of mapping $T$ gives:

$$T(\alpha \mathbf{u} + \beta \mathbf{v}) = \begin{pmatrix} \alpha u_2 + \beta v_2 \\ \alpha u_1 + \beta v_1 \\ (\alpha u_1 + \beta v_1) + (\alpha u_2 + \beta v_2) \end{pmatrix}$$
$$= \begin{pmatrix} \alpha u_2 \\ \alpha u_1 \\ \alpha u_1 + \alpha u_2 \end{pmatrix} + \begin{pmatrix} \beta v_2 \\ \beta v_1 \\ \beta v_1 + \beta v_2 \end{pmatrix}$$
$$= \alpha \begin{pmatrix} u_2 \\ u_1 \\ u_1 + u_2 \end{pmatrix} + \beta \begin{pmatrix} v_2 \\ v_1 \\ v_1 + v_2 \end{pmatrix} = \alpha T(\mathbf{u}) + \beta T(\mathbf{v})$$

  2. Show that $T : \mathbb{R}^2 \rightarrow \mathbb{R}^2$ given by the following mapping is a linear transformation: $$T\begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = \begin{pmatrix} x_2 \\ 3x_1 \end{pmatrix}$$

Linear Transformations

If $T(\mathbf{x})$ is a Linear Transformation, $T(\mathbf{0}) = \mathbf{0}$
Theorem

For any linear transformation $T(\mathbf{x})$, $T(\mathbf{0}) = \mathbf{0}$.

Proof Outline
  1. From the linear mapping definition, $\alpha T(\mathbf{0}) = T(\alpha \mathbf{0}) = T(\mathbf{0})$ for any scalar constant $\alpha$.
  2. If $\alpha T(\mathbf{0}) = T(\mathbf{0})$ for all values of $\alpha$, then $T(\mathbf{0})$ must evaluate to $\mathbf{0}$.
Corollary

If $T(\mathbf{0}) \neq \mathbf{0}$ for a given mapping, it cannot be a linear transformation.

Linear Transformations

A Linear Transformation That is Not on $\mathbb{R}^n$

Consider the definite integral operator $I : C[a, b] \rightarrow \mathbb{R}$ defined by:

$$I(f) = \int_{a}^{b} f(t) \, dt$$

(where $C[a, b]$ defines the vector space of continuous functions on $[a, b]$).

We check $I(\alpha f + \beta g) = \alpha I(f) + \beta I(g)$ for $f, g \in C[a, b]$ and scalars $\alpha, \beta \in \mathbb{R}$:

$$I(\alpha f + \beta g) = \int_{a}^{b} [\alpha f(t) + \beta g(t)] \, dt$$ $$= \alpha \int_{a}^{b} f(t) \, dt + \beta \int_{a}^{b} g(t) \, dt$$ $$= \alpha I(f) + \beta I(g) \quad \text{(by calculus properties of linearity)}$$

Linear Transformations

Another Linear Transformation That is Not on $\mathbb{R}^n$

Consider the derivative operator $T = \frac{d}{dx}$ mapping $P_2 \rightarrow P_1$, where $P_n$ is the space of polynomials of degree $n$ or less.

$T$ acts to evaluate the derivative:

$$T(c_1 + c_2x + c_3x^2) = \frac{d}{dx}(c_1 + c_2x + c_3x^2) = c_2 + 2c_3x$$

Can you check that this is a linear transformation?

Matrix Representation

Matrix Form of Mappings

Revisiting the example where $T\begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = \begin{pmatrix} x_2 \\ x_1 \\ x_1 + x_2 \end{pmatrix}$. Let's isolate coefficients into matrix $A$:

$$A = \begin{pmatrix} 0 & 1 \\ 1 & 0 \\ 1 & 1 \end{pmatrix}$$

We can formulate the structure using matrix multiplication:

$$T(\mathbf{x}) = \begin{pmatrix} x_2 \\ x_1 \\ x_1 + x_2 \end{pmatrix} = \begin{pmatrix} 0 & 1 \\ 1 & 0 \\ 1 & 1 \end{pmatrix} \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = A\mathbf{x}$$

It is true in general that any operation defined by $T(\mathbf{x}) = A\mathbf{x}$ forms a valid linear transformation.

Matrix Representation

The Standard Basis

The standard basis in $\mathbb{R}^n$ consists of orthogonal unit column vectors:

$$\mathbf{e}_1 = \begin{pmatrix} 1 \\ 0 \\ \vdots \\ 0 \end{pmatrix}, \quad \mathbf{e}_2 = \begin{pmatrix} 0 \\ 1 \\ \vdots \\ 0 \end{pmatrix}, \quad \dots, \quad \mathbf{e}_n = \begin{pmatrix} 0 \\ 0 \\ \vdots \\ 1 \end{pmatrix}$$
In $\mathbb{R}^2$:
$$\mathbf{i} = \mathbf{e}_1 = \begin{pmatrix} 1 \\ 0 \end{pmatrix}, \quad \mathbf{j} = \mathbf{e}_2 = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$$
In $\mathbb{R}^3$:
$$\mathbf{i} = \mathbf{e}_1 = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}, \quad \mathbf{j} = \mathbf{e}_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}, \quad \mathbf{k} = \mathbf{e}_3 = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}$$

Matrix Representation

Matrix Representation Theorem (1)
Theorem

If $T$ is a linear transformation mapping from $\mathbb{R}^n$ into $\mathbb{R}^m$, there is a unique $m \times n$ matrix $A$ such that $T(\mathbf{x}) = A\mathbf{x}$ for all $\mathbf{x} \in \mathbb{R}^n$. The $j$-th column vector of $A$ is given by transforming standard basis components: $\mathbf{a}_j = T(\mathbf{e}_j)$ for $j = 1, 2, \dots, n$.

Proof Outline:

Let $A = \begin{pmatrix} \mathbf{a}_1 & \mathbf{a}_2 & \dots & \mathbf{a}_n \end{pmatrix}$ where $\mathbf{a}_j = T(\mathbf{e}_j)$.

Any vector $\mathbf{x} \in \mathbb{R}^n$ evaluates as: $\mathbf{x} = x_1\mathbf{e}_1 + x_2\mathbf{e}_2 + \dots + x_n\mathbf{e}_n$

$$\implies T(\mathbf{x}) = x_1 T(\mathbf{e}_1) + x_2 T(\mathbf{e}_2) + \dots + x_n T(\mathbf{e}_n) \quad \text{(by linearity properties)}$$

$$T(\mathbf{x}) = x_1\mathbf{a}_1 + x_2\mathbf{a}_2 + \dots + x_n\mathbf{a}_n$$

Matrix Representation

Matrix Representation Theorem (2)
Proof Outline (Continued):

Expanding components of the column addition $T(\mathbf{x}) = x_1\mathbf{a}_1 + x_2\mathbf{a}_2 + \dots + x_n\mathbf{a}_n$ explicitly:

$$= x_1 \begin{pmatrix} a_{11} \\ a_{21} \\ \vdots \\ a_{m1} \end{pmatrix} + x_2 \begin{pmatrix} a_{12} \\ a_{22} \\ \vdots \\ a_{m2} \end{pmatrix} + \dots + x_n \begin{pmatrix} a_{1n} \\ a_{2n} \\ \vdots \\ a_{mn} \end{pmatrix}$$

This matches row-column expansion configurations for standard matrix multiplication:

$$= \begin{pmatrix} a_{11} & a_{12} & \dots & a_{1n} \\ a_{21} & a_{22} & \dots & a_{2n} \\ \vdots & \vdots & \ddots & \vdots \\ a_{m1} & a_{m2} & \dots & a_{mn} \end{pmatrix} \begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{pmatrix} = A\mathbf{x}$$

Matrix Representation

Example

Find the matrix representation $A$ for the transformation $T: \mathbb{R}^3 \rightarrow \mathbb{R}^2$ given by $T(\mathbf{x}) = (x_1 + x_2, x_2 + x_3)^T$:

Evaluate mapping projections against standard basis vectors:

$$T(\mathbf{e}_1) = T\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} = \begin{pmatrix} 1+0 \\ 0+0 \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$
$$T(\mathbf{e}_2) = T\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 0+1 \\ 1+0 \end{pmatrix} = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$$
$$T(\mathbf{e}_3) = T\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 0+0 \\ 0+1 \end{pmatrix} = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$$

Arranging these output columns together constructs the standard transformation matrix:

$$A = \begin{pmatrix} 1 & 1 & 0 \\ 0 & 1 & 1 \end{pmatrix}$$

2D Rotation and Reflection Matrices

Geometric Interpretation

Suppose you are given the matrix operation $A = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$. How would you describe the transformation $T(\mathbf{v}) = A\mathbf{v}$ geometrically?

Hint: Evaluate with an arbitrary test vector $\mathbf{v} = \begin{pmatrix} v_1 \\ v_2 \end{pmatrix}$:

$$T(\mathbf{v}) = A\mathbf{v} = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix} \begin{pmatrix} v_1 \\ v_2 \end{pmatrix} = \begin{pmatrix} v_1 \\ -v_2 \end{pmatrix}$$

Conclusion: This transformation reflects coordinates directly across the horizontal $x$-axis.

Now try it yourself: Describe the geometry if $A = \begin{pmatrix} -1 & 0 \\ 0 & 1 \end{pmatrix}$.

2D Rotation and Reflection Matrices

Reflection across the $x$-axis

When coordinate points undergo reflection across the $x$-axis, the mapping follows:

$$\begin{pmatrix} x \\ y \end{pmatrix} \mapsto \begin{pmatrix} x \\ -y \end{pmatrix}$$

Tracing individual transformations across the standard basis vectors:

$$\begin{pmatrix} 1 \\ 0 \end{pmatrix} \mapsto \begin{pmatrix} 1 \\ 0 \end{pmatrix} \quad \text{and} \quad \begin{pmatrix} 0 \\ 1 \end{pmatrix} \mapsto \begin{pmatrix} 0 \\ -1 \end{pmatrix}$$

Grouping the output columns gives the standard reflection matrix:

$$A = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$$
