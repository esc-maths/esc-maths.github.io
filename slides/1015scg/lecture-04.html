Linear Regression

Slope and intercept form

\(\hat{y} = mx + b\)

Residuals:

\(e_i= y_i - \hat{y}\)

where \(\ds \hat{y} = m x_i + c\)

We want to minimize

\( \ds \sum_{i}\) \(e_i^2\) \(= \ds \sum_{i}\left(y_i - \hat{y}\right)^2\)


Exploration



The linear model - least squares solution

Model: \( y_i = \beta_0 + \beta_1 x_i + \varepsilon_i \)

Least-squares objective (minimise sum of squared residuals):

\[ \min_{\beta_0,\beta_1} \; S(\beta_0,\beta_1) \quad\text{where}\quad S(\beta_0,\beta_1)=\sum_{i=1}^n (y_i - \beta_0 - \beta_1 x_i)^2 \]

Closed-form solution (best-fit slope and intercept):

\[ \hat\beta_1 = \frac{\sum_{i=1}^n (x_i-\bar{x})(y_i-\bar{y})} {\sum_{i=1}^n (x_i-\bar{x})^2}, \quad\quad \hat\beta_0 = \bar{y} - \hat\beta_1 \bar{x} \]

The Linear Regression Model

For a dataset of pairs \((x_i, y_i)\), we assume that the relationship between \(x\) and \(y\) can be described by a straight line.

\( y_i = m x_i + b \)

• \(b\) (intercept): the predicted value of \(y\) when \(x=0\).

• \(m\) (slope): how much the predicted value of \(y\) changes for each 1-unit increase in \(x\).

Least-squares estimates: \(\;\ds m = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sum (x_i-\bar{x})^2}, \;\, b = \bar{y} - \hat{m}\,\bar{x} \)
