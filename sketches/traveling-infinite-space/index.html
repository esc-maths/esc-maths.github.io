Navigation 🚀

Navigate with the arrow keys, or click once and move the mouse to look around.

  • W → Thrust
  • S → Drag
  • D → Roll right
  • A → Roll left

More controls 🕹️

  • Enter → New random seed
  • T → Info
  • [ → Decrease Objects
  • ] → Increase Objects
  • N → Toggle noise
  • L → Toggle layers
  • / → Flip vertically
  • F → Toggle fullscreen
  • C → Show/Hide this menu 😶‍🌫️
